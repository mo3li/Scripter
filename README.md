# Scripter

Claude Code skills for writing viral video scripts.

## Skills

- **viral-script-architect** (`.claude/skills/viral-script-architect/`): writes, rewrites, shortens, expands and critiques scripts for TikTok, Reels, Shorts and long-form YouTube. Supports 10 rewrite modes (Clean, Viral, Yapping, Shorten, Long-form, Story, Authority, Sales, Reply, Personal Brand) and defaults to Egyptian Arabic for Arabic requests.

## Usage

Open this repo in Claude Code and ask naturally, e.g.:

- `اكتبلي سكريبت ريلز Yapping عن أهمية أول ٣ ثواني في الفيديو`
- `اختصر السكريبت ده لـ ٤٥ ثانية من غير ما يضيع المعنى: ...`
- `/viral-script-architect MODE 9 REPLY — الكومنت: "المحتوى التعليمي مبيجبش فلوس"`

To use it in every project, copy the folder to `~/.claude/skills/viral-script-architect/`.
