# Self-Review Loop (mandatory before delivering any script)

A first draft is never the delivery. Every script goes through this loop:

1. **Draft** the script.
2. **Read it as the viewer**, out loud in your head, line by line, at speaking speed.
3. **Run every check below** and write down (to yourself) each line that fails and why.
4. **Rewrite** those lines. Cut before you add.
5. **Repeat from step 2** on the new version. Stop only when a full pass finds nothing to fix.

Don't show the drafts or the check results to the user unless they ask. Deliver the final version only.

## The checks

| # | Check | Fails when… |
|---|---|---|
| 1 | **Hook is sharp** | It could open any other video, it warms up before the point, or it needs the second line to make sense |
| 2 | **No filler** | A word or line can be removed without losing meaning (see the banned list below) |
| 3 | **Every line earns the next** | A line explains what the previous line already made clear, or the viewer could skip it and miss nothing |
| 4 | **Tension holds** | Two or more lines in a row with no new information, no turn, no question and no payoff |
| 5 | **Spoken, not written** | It sounds like an article, a translation, or a presentation. Read it aloud: would an Egyptian creator say it this way to a friend? |
| 6 | **Spontaneous (yapping)** | Every line has the same length and rhythm, there's no reaction, no aside, no short punch line, nothing that sounds like thinking out loud |
| 7 | **Specific** | A general word where a concrete one exists ("حاجات كتير" → the actual thing; "الشارع" → "الشرخ اللي في الرصيف") |
| 8 | **Professional** | Rambling, over-explaining, begging for attention, fake hype, or a list read like a slide. Confident people say it once, short, and move on |
| 9 | **Lists don't sound like lists** | "واحد… اتنين… تلاتة…" repeated with the same sentence shape. Vary how each point enters, or drop the numbering |
| 10 | **Ending lands** | The last line before the CTA is weaker than a line in the middle, or it just repeats the lesson |

All the other rules still apply in every pass: length (§22), regenerate (§23), `[verify]` and no invented facts (§12).

## Banned filler and weak openers (Egyptian Arabic)

Cut them, or replace them with the point itself. One is allowed only when it does a real job (a genuine turn), never as a habit.

| Filler / weak opener | Why it's weak | Do this instead |
|---|---|---|
| خليني أقولك حاجة… / تعالى أقولك… / هقولك حاجة | Announces instead of saying | Say the thing |
| بص بقى… / بص… at the start of lines | A tic after the first use | Drop it |
| الموضوع ببساطة… / بكل بساطة / الحكاية سهلة وبسيطة | Promises simplicity, adds nothing | Show it's simple by being short |
| في الحقيقة / الحقيقة إن / بصراحة (as a habit) | Implies the rest wasn't true | Drop it |
| حاجة مهمة جدًا / النقطة دي مهمة | Tells instead of showing | Make the line itself hit |
| ركّز معايا / خد بالك (more than once) | Begging for attention | Earn it with a turn or a surprise |
| طب إيه الحل؟ / طب ليه؟ (when the answer is obvious) | Fake question that slows it down | Go straight to the answer |
| والأهم من كده / ومش بس كده | Filler bridge | Start the next point directly |
| يعني إيه الكلام ده؟ | Stalls | Give the example |
| زي ما قلتلك / زي ما قلنا | Repetition | Cut the repeat |
| في الفيديو ده هتكلم عن… / النهارده هنتكلم عن… | Agenda, not a hook | Open with the claim |
| السلام عليكم، أنا فلان… (as the first line) | Greeting before the hook | Hook first; name later or never |
| "…" at the end of every line | Fake drama, reads flat | Use pauses only where a real beat is |

## Before / after

**Filler and announcing**
- ❌ خليني أقولك حاجة تقيلة شوية: محدش بيشتري اللوجو بتاعك.
- ✅ اللوجو بتاعك مش هيقفلك ولا صفقة.

**Fake question**
- ❌ طب الدليل ده شكله إيه؟ مش بوستات أكتر. تلات حاجات تقدر تصورها:
- ✅ الدليل إن العميل يشوفك وانت شغال.

**Written, not spoken**
- ❌ التلاتة مشتركين في حاجة واحدة: الواحد بيطلع منهم بحاجة يستخدمها.
- ✅ التلاتة فيهم نفس الحاجة: خرجت منهم بحاجة هتستخدمها.

**Slide-list rhythm**
- ❌ واحد: … اتنين: … تلاتة: … (same shape each time)
- ✅ First point stated flat, second one as a question, third one with a reaction ("وده اللي جابله أكتر فولو").

**Over-explaining**
- ❌ عشان الـ Views حاجة… والمتابعين حاجة تانية خالص. الريلز التحفيزية والترند والجدل بتجيب مشاهدات وكومنتات وشير. بس نادرًا ما حد بيدوس Follow بعدها.
- ✅ الناس اتفرجت، ضحكت، عملت شير… ومشيت.

**Weak ending**
- ❌ وكده بدل ما تسأل "أعمل محتوى عن إيه؟" هيبقى عندك ١٠ فيديوهات.
- ✅ السؤال اللي بيتكرر هناك… هو فيديوك الجاي.
