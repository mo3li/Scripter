# Broker Lexicon: real-estate talk (Egyptian street + Dubai market)

Words and phrases the user collected from how brokers actually talk. Use them to make scripts sound like someone from inside the field.

Two ways to use them:
1. **Inside the business:** the normal term in a serious script.
2. **As the joke:** the "broker dictionary" format (what the broker says vs what it really means), built with the comedy structure in `writing-disciplines.md` §5.

Gulf rule (`brand-voice.md` §3): deep Egyptian slang doesn't always land with Gulf viewers. In a serious script, use the plain term. In the comedy format, the Egyptian phrase *is* the joke, so keep it, and always follow it with the plain meaning.

## Rules

- **Laugh at the profession, including ourselves, never at the buyer.** Mohamed is a broker, so self-deprecation builds trust (`writing-disciplines.md` §5).
- **Never imply a specific developer or project is lying.** The translations are generic jokes.
- **End with real value:** the protection behind the joke. For example:
  - get it in writing
  - check the escrow account
  - check that "finished" is defined in the contract
  - check the handover date and the penalty for delay
- Some of the user's words were unclear in the voice note (e.g. «مياول», «مصلاحة في الجول», «كورانشال», «مترب», «السمع»). Don't use them until the user clarifies.
