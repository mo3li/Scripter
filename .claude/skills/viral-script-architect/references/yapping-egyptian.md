# Yapping & Egyptian Arabic Delivery

## Process

1. **Write the skeleton first** (not shown to the user unless asked): hook, main loop, 2–4 beats, payoff, CTA.
2. **Speak it**, don't write it: convert each beat into how the creator would actually say it out loud.
3. **Roughen lightly**: add a connector, a fragment, a self-correction or an aside, but only where a real person would. One or two per 30 seconds is plenty.
4. **Read it aloud mentally**: if a line sounds like an article, rewrite it.

## Egyptian spoken connectors

Use them naturally and vary them; don't open every line with one.

| Function | Connectors |
|---|---|
| Starting | "بص بقى…", "خليني أقولك حاجة…", "بص، الموضوع ببساطة…", "طيب…", "أنا هقولك…" |
| Adding / continuing | "وكمان…", "والأهم بقى…", "وخد بالك…", "ومش بس كده…" |
| Turning point | "بس هنا بقى المشكلة…", "وهنا بقى الموضوع بيقلب…", "بس استنى…", "لأ، والأغرب…" |
| Explaining why | "عشان…", "ليه؟ عشان…", "والسبب بسيط…", "يعني إيه الكلام ده؟" |
| Honesty / confession | "بصراحة…", "هكون صريح معاك…", "أنا نفسي كنت بعمل كده…" |
| Emphasis | "بجد…", "خالص", "أصلًا", "نهائي", "ده بالظبط اللي…" |
| Self-correction (sparingly) | "…لأ استنى، خليني أقولها بشكل أوضح:" |
| Reaction | "تخيل!", "حرفيًا", "وده اللي محدش بيفهمه" |
| Wrapping up | "فالخلاصة…", "من الآخر…", "فلو هتاخد حاجة واحدة من الفيديو ده…" |

## Natural CTA phrasing (Egyptian)

- "لو الفيديو ده فادك، احفظه عشان هترجعله."
- "ابعته لصاحبك اللي بيعمل الغلطة دي."
- "اكتبلي في الكومنتات [كلمة] وأنا هبعتلك [الحاجة]."
- "تابعني عشان الجزء التاني."
- "لو عايز نشتغل سوا، اللينك في البايو."

Match the CTA to the objective (§9). Only one primary CTA per short.

## Language rules

- Spoken Egyptian (عامية مصرية), not فصحى, unless the topic or user needs formal Arabic.
- Keep marketing/tech terms in English as creators say them: Hook, Retention, CTA, Content, Funnel, Lead, Sales, Branding, Personal Brand, Open Loop, Views, Reach, Engagement.
- Don't literally translate English idioms; find the Egyptian equivalent or rephrase.
- Write Arabic numerals or digits consistently within one script (٣ or 3), following the user's own style.
- Keep gender/addressing consistent (مخاطب مذكر by default, or neutral/plural "انتوا" if the audience is mixed and the user prefers). Follow the user's lead.

## Avoid

- فصحى stiffness: "إن هذا الأمر في غاية الأهمية" → "الحتة دي مهمة جدًا".
- Translated AI clichés: "في عالمنا المتسارع", "دعونا نغوص", "أطلق العنان".
- Stacked rhetorical questions ("هل تعلم؟ هل فكرت؟ هل جربت؟").
- Over-the-top fake stumbles or filler ("يعني يعني… اممم…") repeated.
- Every line starting with "وبعدين".

## Before → After example

**Before (written, stiff):**
> من أهم الأخطاء التي يقع فيها صناع المحتوى هو عدم الاهتمام بالثواني الأولى من الفيديو، مما يؤدي إلى انخفاض نسبة المشاهدة.

**After (yapping, Egyptian):**
> بص… أكتر غلطة بشوفها عند الناس اللي بتعمل Content؟
> إنهم بيضيّعوا أول تلات ثواني.
> بيبدأ الفيديو بـ "أهلًا بيكم، النهارده هنتكلم عن…"
> وخلاص… الناس مشيت.
> ليه؟ عشان انت لسه مقولتش حاجة تخليهم يستنوا.
