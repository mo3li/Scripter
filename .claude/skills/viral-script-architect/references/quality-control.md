# Quality Control

Run this before delivering any script. Scores stay internal unless the user asks for them.

## Scorecard (1–10)

| Category | Question | Critical for |
|---|---|---|
| Hook | Would the target viewer stop scrolling in 1–3s? | All |
| Clarity | Can someone understand it on one listen, sound on, no rewind? | All |
| Curiosity | Is there a real gap that pulls them forward? | All |
| Retention | Does every line earn the next? Any dead spots? | All |
| Pacing | New beat every few seconds (short) / every 60–90s (long)? | All |
| Novelty | Is there at least one thing they haven't heard framed this way? | Awareness, Authority |
| Emotional impact | Do they feel something (relief, surprise, anger, hope, recognition)? | Story, Personal Brand |
| Value | Do they leave with something usable? | Education, Authority |
| Authenticity | Does it sound like this creator, not an AI? | All |
| Payoff | Is the hook's promise fully kept? | All |
| CTA | One clear action, matched to the objective and earned by the value? | Leads, Sales, Followers |
| Shareability | Would someone send it to a specific person? | Awareness, Engagement |
| Saveability | Is there something worth coming back to? | Education |
| Conversion potential | Does it move a viewer closer to becoming a lead/buyer? | Leads, Sales |

If any category that's critical for this script's objective is below 8, revise before presenting.

## Red flags checklist

- [ ] The hook promises something the script doesn't deliver
- [ ] A statistic, result, testimonial or quote that the user didn't provide (flag with `[verify]` or remove)
- [ ] An open loop that's never closed
- [ ] The first line is a greeting or "today we'll talk about…"
- [ ] Two consecutive lines that say the same thing
- [ ] Generic AI phrasing (English or Arabic)
- [ ] Formal Arabic where Egyptian was expected
- [ ] More than one primary CTA in a short
- [ ] Stage directions not in [brackets]
- [ ] Script length doesn't match the requested duration (new short-form: 30s max; rewrite of an existing script: keep its original length and points)
- [ ] The user's original meaning or key point was changed or lost

## Critique format (when the user asks for feedback on their script)

Keep it short and actionable:

1. **What's working** (1–3 bullets): keep these.
2. **What's hurting retention** (1–5 bullets): each with the line quoted and why.
3. **The rewrite**: the improved script.
4. **Scores** only if requested.
