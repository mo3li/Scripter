# Script Structures

Pick the structure from the idea, not the other way around.

## Choosing a body structure

| Structure | Use when | Watch out for |
|---|---|---|
| A. Problem → Cause → Solution | Audience feels the pain but misdiagnoses it | Cause is where the insight lives; don't rush it |
| B. Hook → Proof → Framework → Example → Payoff | Authority/educational content with a real result | Proof must be real and brief |
| C. Story → Conflict → Discovery → Lesson | A personal or client story carries the lesson | Enter the story late (at the tension), leave early |
| D. Claim → Counterclaim → Explanation → Proof | Contrarian or myth-busting takes | State the counterclaim fairly or you lose credibility |
| E. Mistake → Consequence → Fix | Practical "stop doing X" content | Consequence should be concrete and felt |
| F. Before → After → Mechanism | Transformations, case studies, sales | Mechanism is what makes it believable and saveable |
| G. Question → Investigation → Answer | Curiosity-driven explainers | Investigation needs escalating clues, not filler |
| H. Open Loop → Progressive Reveal → Payoff | High-curiosity shorts | Reveal in steps; each step is a mini-payoff |
| I. List → Escalation → Strongest Point → Payoff | Tips/lists | Order from good to best; save the best for last but tease it early |
| J. Yapping Narrative: Hook (mid-thought) → Gap (did / expected / happened) → Confession → One-line Lesson → Close the Loop | Opinion, personal brand, talking head, lessons learned | Confession must be real; lesson is one sentence; ending calls back to the hook. See `yapping-egyptian.md` |

## Short-form skeleton (15–60s)

```
0–3s    HOOK        gap + viewer selection
3–8s    CONTEXT     just enough to understand the stakes (often skip)
8–45s   BODY        chosen structure; a new beat every 3–6s
        MINI-PAYOFFS keep rewarding attention
45–55s  PAYOFF      close the main loop, clearly
55–60s  CTA         one action, tied to the value just delivered
```

Rule of thumb: if a line doesn't add new information, a new question, or a new feeling, cut it.

## Long-form outline (8–20 min)

```
HOOK (0–30s)        strongest moment / question / result up front
PROMISE             what they'll get by the end, specifically
CONTEXT             why this matters now, stakes
QUESTION            the central question that drives the video
ESCALATION          section 1 → answer part, raise a new question
DISCOVERY           section 2 → new information, surprise
COMPLICATION        "but here's the problem…", stakes rise
REVELATION          the key insight / mechanism
PAYOFF              fulfil the promise completely
CONCLUSION + CTA    recap in one line, next video / subscribe / offer
```

- Re-engagement point roughly every 60–90 seconds: a new question, stake, surprise, or payoff.
- Tease later sections early ("and the third one is the one that surprised me the most").
- Each chapter title should work as a mini-hook.

## Reply video (MODE 9)

```
COMMENT     show it on screen
HOOK        react with a reframe that concerns everyone, not just the commenter
REFRAME     "the real question here is…"
ANSWER      direct, no hedging
VALUE       what the wider audience can take from it
PROOF       example, result, story
PAYOFF      close the loop
CTA         e.g. "comment your question and I'll answer the best one"
```

Tone with critics: confident, fair, never defensive or mocking. The audience is watching how you handle it.

## Sales script (MODE 8)

```
HOOK            the painful problem or the desired result
PROBLEM         make it specific and felt
AGITATE         the cost of leaving it (be honest, no fear-mongering)
MECHANISM       why the usual fixes fail, and what actually works
PROOF           real results, process, demonstration
OBJECTIONS      handle the 1–2 biggest ones naturally
OFFER           what they get, for whom it is (and isn't)
RISK/TRUST      guarantee, process clarity, what happens next
CTA             one clear, low-friction next step
```

Never invent testimonials, numbers, or guarantees the user hasn't provided.

## Story mode (MODE 6)

- Start at the moment of tension, not at the beginning.
- One character the viewer relates to; clear want; clear obstacle.
- Show the turning point concretely (what was said, seen, done).
- The lesson is earned by the story, stated in one line, never lectured.

## Authority mode (MODE 7)

- Show competence through specifics (process, numbers, examples), not through claims about yourself.
- Name what most people get wrong, explain why, then show the better way.
- Confident, not arrogant: no belittling the audience.

## Personal brand mode (MODE 10)

- The idea is the vehicle; the creator's perspective, opinions, humor and values ride on it.
- Include one "only I would say it like this" moment: a personal story, stance, or signature phrase.
