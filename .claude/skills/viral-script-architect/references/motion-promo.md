# Scripts for Motion / Promo Films

Use this when the script will become an animated promo, product film, motion graphic or text-on-screen video (no one talking to camera). This includes scripts handed to a motion-graphics tool.

## How these films are built

A motion film is cut into **beats**. Each beat is one idea on screen, usually with a line of at most ~5 words. The tool (or editor) picks the beats from the script, so the script has to already contain clean beats.

## Length

| Use | Duration | Beats |
|---|---|---|
| Social (Reels, TikTok, Shorts, Stories) | 15–20s | ~4–5 |
| Launch film / website hero | ~30s | ~6–7 |
| Under 12s | Feels rushed | Avoid |
| Over 45s | Needs a real story to justify it | Only when asked |

Aspect ratio: 9:16 for Reels/TikTok/Shorts/Stories, 1:1 for feed and LinkedIn, 16:9 for YouTube, website and decks. Ask for duration and ratio if the user didn't give them. The tool can't decide those.

## Writing rules

1. **Write for the ear.** Say what the product does the way you'd say it to a friend.
2. **4–6 ideas maximum.** A 20-second film holds about 5 beats. If there are 12 points, choose the best 5 yourself, don't let the tool choose.
3. **Lead with the sharpest line.** The first beat is the one people actually watch.
4. **Kill the adjectives.** "Powerful, intuitive, best-in-class" gives nothing to animate. "Deploy in nine seconds" does.
5. **Numbers are gold.** A real number gets its own shot, e.g. a big figure slamming in. It will look better than any adjective. Only real numbers.
6. **One idea per beat.** Never stack two claims in one line.
7. **Short lines.** Aim for ≤ 5 words per on-screen line. Longer sentences get cut anyway, so cut them yourself.

**Weak:** "Meridian is a comprehensive, enterprise-grade scheduling solution that leverages intelligent algorithms to optimise calendar management."
**Strong:** "Meridian finds meeting times nobody hates. It reads every calendar on your team. Cut 40% of your meetings. Free under ten people."
The strong version has four clean beats. The weak version has none.

## Output format

Give a beat sheet the user can check before anything is rendered:

```
DURATION: 20s · RATIO: 9:16

BEAT 1 (0–4s)  · [shot type, e.g. big type slam]
ON SCREEN: …
VO (optional): …

BEAT 2 (4–8s)  · [shot type, e.g. number reveal]
ON SCREEN: …

…

END CARD: [brand / CTA]
```

- Keep the brand colours and the CTA the user gives you. Never invent product claims, prices or numbers.
- When the user gives a website instead of a script, extract 4–6 true, concrete points from it and write the beats from those.
- After delivering, say what you cut from the source and why, in one line.

## Refining a film

Translate vague notes into specific beat changes:

| User says | Change |
|---|---|
| "Beat 3 is too fast" | Lengthen that beat, keep the rest |
| "Make it pop more" | Stronger reveal and more contrast on key beats |
| "Too busy" | Fewer objects per beat, longer holds |
| "Different opening" | Swap the first beat's shot type or line |
| "Drop that scene" | Cut the beat and redistribute timing |
