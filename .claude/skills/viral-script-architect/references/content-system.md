# The Content System: Signals, Idea Test, Script Map, Strategy

Load this for:
- a content strategy, content plan or series (CONTENT PLAN mode)
- a full production package (hooks for audio, visual and text, caption, keywords)
- diagnosing why a video underperformed

Principle: good content comes from a repeatable system, not luck. The order is: understand the platform → pick an idea that stops the mind → hook → script that holds attention to the end → result.

## 1. The 5 signals every video is judged on

The platform measures viewer behaviour, not the creator's name or intentions. Write every script to move these five:

| # | Signal | Question | What the script controls |
|---|---|---|---|
| 1 | **Stop rate** | Did they stop scrolling? | Hook strength in the first seconds: spoken line, on-screen text and first visual |
| 2 | **Retention** | How much did they watch? | Value and flow: a reason to stay after the hook, no filler, micro hooks |
| 3 | **Rewatch** | Did they watch again? | A dense or surprising idea, a loop ending, a detail worth catching twice |
| 4 | **Shares** | Did they send it to someone? | Usefulness for a specific person ("ابعته لصاحبك اللي…"), an opinion people want to spread |
| 5 | **Engagement** | Did they comment, save, follow? | Emotional connection, a question worth answering, value worth saving, a clear CTA |

To diagnose a weak video, find the signal that broke:
- Low views and a low stop rate → rewrite the hook and first visual.
- Stop rate is fine but retention drops → fix the value line and the development.
- Good retention but few shares or saves → the payoff isn't useful or surprising enough.

## 2. The idea test (before writing anything)

**Strong idea = attention + curiosity + emotion.**

- **Attention**: it names something the viewer cares about.
- **Curiosity**: it makes the mind ask a question it wants answered now.
- **Emotion**: it touches a pain, a desire, or a conflict.

| Weak idea | Strong idea |
|---|---|
| "النهارده هعلمك حاجة عن المحتوى" | "ليه ناس بتفشل مع إنها أشطر منك؟" |
| Repeats what everyone says, no question, no feeling | Sparks curiosity, touches a pain or a conflict, promises a real reveal or benefit |

If the idea fails the test, fix the idea first. Editing won't save an idea that doesn't stop the mind.

## 3. Hook formula

**Pattern interrupt + curiosity = strong hook.**

Three dependable types:

| Type | What it does | Example |
|---|---|---|
| **Pain** | Touches the problem directly | "ليه مشاهداتك وقعت فجأة؟" |
| **Curiosity** | Opens a question in the mind | "ليه ناس بتفشل مع إنها أشطر منك؟" |
| **Shock** | Breaks the viewer's expectation | "أغلب اللي بيشتروا أوف بلان بيفهموا البند ده غلط" (only with a real basis) |

Weak: "النهارده هنتكلم عن…" is generic and creates no question.
Strong: "لو فيديوهاتك مش بتوقّف الناس في أول ٣ ثواني… خلاص، انتهت." is specific and creates tension.

Other types to rotate: debate, myth-busting, question, desire, problem. More in `hooks.md` and `hook-bank.md`. When labeling hooks, use the mechanism names from `hooks.md` (Pain ≈ Mistake or Warning, Curiosity ≈ Question, Shock ≈ Contrarian).

## 4. The script map (5 stages in order)

There is no fixed length; the video is as long as the idea needs. The timings below are an example for a ~60s video, not a target.

| # | Stage | Job | Example timing in a ~60s video |
|---|---|---|---|
| 1 | **Hook** | Stop the scroll | 0–3/6s |
| 2 | **Value** | Give a clear reason to keep watching | 3–10/13s |
| 3 | **Development** | Expand the idea with explanation, numbers, examples or a story | 10–40s |
| 4 | **Peak / payoff** | The strongest point: the surprise, the real secret, the key takeaway | last ~15s |
| 5 | **CTA** | One clear action | last 3–5s |

Examples by stage:
- **Value line**: "في الفيديو ده هديك ٣ خطوات عملية…", "بعدها هتعرف الطريقة الصح خطوة بخطوة", "آخر نقطة هي أهمها".
- **Payoff openers**: "المفاجأة بقى…", "السر الحقيقي هو…", "الخلاصة…".

Rules:
- **The value line is a promise, not an agenda.** "هديك ٣ خطوات…" works; "النهارده هنتكلم عن…" doesn't. In a very short script, skip it when the hook already promises the payoff.
- **Hook before value, always.** Leading with the value and hooking late makes retention drop fast. Hook first, then value, keeps it rising.
- **The best script is the clearest, not the longest.** Clarity = higher retention.
- Strong script = clarity + logical flow + emotion + a peak moment + one clear CTA. If any stage is weak, retention starts dropping there.

### Yapping and the map
In YAPPING (structure J), the Gap is the Value stage, the Lesson is the Peak, and the CTA comes right after the Close the loop line. See `yapping-egyptian.md`.

### Alternate 5-part short: Hook → Context → Value → Payoff → CTA
- **Context**: make the viewer feel it's about them. *"أكيد مرّ عليك يوم كامل وإنت لسه محتار تنزّل إيه."*
- **Value**: practical, simple, and usable right away.
- **Payoff**: paint the result they'll get and how things look after.
- **CTA**: one action only. Don't split their attention.

### Micro hooks (re-hooks)
In anything longer than ~30s, add a small re-hook every 15–20 seconds to renew attention:
"بس خلي بالك…" · "وهنا المشكلة…" · "والأخطر من ده كله…" · "وهنا المفاجأة…" · "استنى، لسه الأهم…"

Every re-hook must lead to something new: a new point, a stake, or a reveal. Never use one as empty filler.

## 5. Full production package (only when asked)

When the user asks for a "full package" or everything they need to publish, deliver:
- The script (Hook → Value/Context → Development → Payoff → CTA) in its code block, as usual.
- **3 spoken (audio) hooks**, **3 visual hooks** (the first shot or action) and **3 text hooks** (on-screen overlay), each labeled by mechanism.
- **Caption**: first line hooks, 2–3 short lines, then the CTA.
- **Keywords**: 5–10 search terms people type about this topic, useful for captions, on-screen text and spoken lines (in-app search). Hashtags only if the user wants them.

## 6. Capturing the creator's voice

The more real examples, the closer the script sounds to the creator. When the user shares their scripts or videos, note:
- **Signature phrases** they repeat (e.g. "خليني أقولك الحقيقة", "تخيل معايا").
- Sentence length, level of formality, humour, and how they open and close.
- Favourite structures and the type of CTA they use.

Reuse these naturally, not in every line. Only use phrases that actually appear in the user's material. Never invent a "signature phrase" for them.

## 7. Content strategy (CONTENT PLAN mode)

### 7a. Discovery (only what's missing)
Before a strategy or a batch of ideas, make sure you know the following. Ask **one question at a time**, and only for what the user hasn't already told you or you can't infer.
- For a single script, don't block on this. Use sensible defaults and state them.

1. Brand or project name
2. The product or service, in detail
3. Target client: age, gender, country, job, experience level
4. The result they want
5. Their top problems
6. Their top desires or goals
7. Their top fears or objections to buying or deciding
8. Wrong beliefs the audience holds
9. Questions the user gets asked repeatedly
10. What sets the user apart from competitors
11. Main competitors
12. What they post now
13. What worked best before
14. What flopped
15. The current goal: views, followers, trust, leads, or direct sales

### 7b. Strategy
- **Audience analysis**: problems, desires, fears, questions, beliefs.
- **Content pillars**: 3–5 recurring themes the account owns.
- **Funnel mapping**:
  - **TOF** (top of funnel): broad reach, problems and myths, for people who don't know the user yet.
  - **MOF** (middle): method, proof and stories that build trust.
  - **BOF** (bottom): offer, objections and case results that turn followers into clients.

### 7c. Ideas
Generate ideas per funnel stage (default 20 TOF + 20 MOF + 20 BOF when a full plan is requested; fewer if the user asks). For each idea give:
- **Problem**: the real audience pain or desire it's tied to. Every idea must tie to one.
- **Angle**: see `idea-multiplication.md`.
- **Goal**: views, trust, leads, or sale.
- **Content type** or format.

### 7d. Before writing a script from the plan, decide
- **Phase**: TOF, MOF or BOF.
- **Approach**: educate, story, myth-bust, reply, proof, offer…
- **Tactics**: the hook type, open loop, contrast, numbers, demo…
- **Angle**: the specific take.

State each choice with a one-line reason, then write the script. Pair this with the 9-step agreement ladder in `storytelling-structures.md` when the plan builds toward a sale.

## 8. Specialist hats

For big requests, work in separate passes, like a small team:
1. **Ideas**: find and test ideas (§2).
2. **Scripts**: turn approved ideas into scripts.
3. **Analysis**: diagnose which signal broke on an existing video (§1).
4. **Ads**: ad copy and landing-page copy (use SALES mode).

## Truth note

Guides like these often quote dramatic stats (e.g. "90% of creators fail", or a funnel where "100 start → 1 succeeds"). Don't repeat them in scripts as facts unless the user has a real source. Use them only as illustration, or rephrase without the number.
